# Домашняя работа — кластерные индексы

Используется база `БД2`.

Таблица `dbo.ClusterIndexTest`:
- 5 столбцов;
- 1 000 000 строк;
- данные заполняются автоматически через `INSERT ... SELECT`;
- до создания индекса выполняется SELECT;
- включается `SET STATISTICS IO ON`;
- затем создаётся `CREATE CLUSTERED INDEX ... ON ...`;
- тот же SELECT выполняется повторно для сравнения.

Фактические числа `logical reads`, `physical reads`, `scan count` и времени
нужно получить при запуске SQL в SSMS, так как они зависят от конкретного
экземпляра SQL Server и состояния его кэша.
